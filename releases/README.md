# Releases

Esta carpeta contiene únicamente las versiones estables exportadas de la documentación del Proyecto Simbiosis (por ejemplo, en PDF), correspondientes a líneas base ya declaradas.

**No es la fuente editable.** La fuente canónica de cada documento es su archivo Markdown en `docs/`. Cada exportación publicada aquí debe corresponder a una línea base registrada en [`../CHANGELOG.md`](../CHANGELOG.md) y a una etiqueta de Git.
